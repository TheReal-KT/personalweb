# Personal Web Design Language

## Positioning
This site should feel like a live product logbook, not a generic portfolio. The page needs to communicate active work, design taste, and engineering clarity in the first screen.

## Visual direction
- Warm paper background with deep ink text.
- Cobalt blue is the primary signal color for active states and system emphasis.
- A restrained orange is used for contrast moments, not as the default accent everywhere.
- Panels should feel soft, editorial, and structured rather than glossy or overly futuristic.

## Typography
- Display: expressive, high-character headings for major statements.
- Body: clean and readable long-form copy.
- Mono: metadata, labels, status, and small system language.

## Layout rules
- Lead with one strong statement.
- Use large panels instead of many small fragments.
- Pair narrative copy with compact evidence such as status tags, chips, and focus labels.
- Keep sections spacious on desktop and stacked cleanly on mobile.

## Interaction rules
- Motion should support hierarchy, not distract.
- Section reveals should be smooth and understated.
- Hover states should feel tactile through lift, contrast, or border changes.
- Fine-pointer cursor effects should never appear on touch-first devices.

## Content rules
- Prioritize current projects over generic biography copy.
- Use concise, product-oriented descriptions.
- BLVNK stays intentionally minimal.
- Active projects should read like real work in progress, not finished case studies.
